## ✨ Key Highlights & Features

### 1. 🔍 Interactive Analytical Sandboxes
- **D3.js Portfolio Analytics Engine**: Live multi-series time-series visualizer with moving averages, conversion metrics, date range filters (7d / 30d / 90d), and CSV dataset exports.
- **PriorityPe RICE Simulator**: Interactive product prioritization engine with dynamic Impact and Effort weighting sliders that re-ranks UPI feature themes in real time.
- **Financial Distress & SHAP Simulator**: Early-warning distress calculator benchmarked across 78,682 financial filings with real-time SHAP feature contribution breakdowns.
- **Interactive SQL Playground**: In-browser SQL execution environment with pre-loaded enterprise schemas, CTEs, and window functions.
- **Azure Streaming Architecture Visualizer**: Step-by-step telemetry pipeline illustrating Bronze–Silver–Gold Lakehouse layers, Databricks PySpark streaming, and Synapse SQL star-schema modeling.
- **Cohort Retention Matrix**: Interactive heatmap analyzing user retention drop-offs, churn factors, and customer lifetime value (CLV).

### 2. 📑 Deep-Dive Case Studies & Proof
- **PriorityPe**: NLP review mining and RICE prioritization across 6,000+ Google Play Store reviews for PhonePe, Google Pay, and Paytm.
- **Bankruptcy Risk Suite**: SQL ratio analysis, Power BI dashboards, and XGBoost (0.857 ROC-AUC) modeling with transparent SHAP interpretability for credit committees.
- **MediFlowRT**: Real-time hospital operations telemetry with sub-second stream processing on Azure and star-schema dimensional modeling.

### 3. 🎯 Recruiter-Ready Tools
- **Role-Tailored PDF Resumes**: Instant generation and download of 4 dedicated resumes:
  - *Business Analyst* (KPI reporting, churn reduction, executive storytelling)
  - *Product Analyst* (RICE prioritization, NLP review mining, roadmapping)
  - *Data Engineer* (Azure, PySpark, Lakehouse, Star-Schema ETL)

- **Global Command Palette (`⌘K` / `Ctrl+K`)**: Rapid keyboard-driven navigation across all sections, demos, case studies, and downloads.

## 🚀 Getting Started (Local Development)

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/suvampriyaranjansahoo/PORTFOLIO.git
   cd PORTFOLIO
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:3000`.

4. **Build for production:**
   ```bash
   npm run build
   ```
